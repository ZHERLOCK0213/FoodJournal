## 该阶段交互与结果

1. 选器官只改变器官视觉焦点，不过滤食物粒子。静止时其他器官不透明度 13%；预演中 32%，方便辨认下游。
2. 份量选择 50 / 100 / 200 / 300g，默认 100g。开始时冻结本份食物、克重；后续选择不改变既有小结。
3. 预演时间约 7.2 秒（非真实消化时间）。完成后自动出现「本份消化小结」，向上展开查看每个器官的过程和结果，点击「定位」回到该器官。
4. 关闭后仍能在下方卡片重新查看小结；恢复全貌后可重播。重播不增加摄入记录。
5. 新一份开始、删除、重置会清除过期小结；每份完成后展示自己的小结。

## 科普边界与来源

`MealDigestionJourney` 根据宏量营养成分编排典型过程，不使用旧「器官能力耗尽」模型计算个人产物量。教育性预演不代表实际个人消化结果。

- 蛋白、脂肪、碳水都会触发胰腺消化酶协作，不以血糖阈值决定胰腺是否参与。
- 无纤维食物仍展示大肠吸水等一般作用；不能说鸡胸肉全部进入大肠或全部变成粪便。
- 肝、胆、胰为协作器官，肾为持续发生的代谢延伸；食团不经过它们。金色粒子仍只代表消化道内内容物，不代表未改变的原食物或全部营养。
- 尿液等结果以定性科普描述，不声称一份食物可预测个人尿素、尿酸或血糖变化量。
- 当时数据库成分尚缺统一校核和生熟口径，界面以「成分示例」限定用途；旧报告页的改造在后续阶段推进，见 [开发历史](../../../docs/development-history.md)。这些演示不能用于医疗或个性化膳食判断。

## 可复现导出

在安装 Xcode 命令行工具的 macOS 上，从仓库根目录执行：

```sh
mkdir -p build
swiftc FoodJourney/Models/AnatomyArtwork.swift scripts/export-anatomy.swift -o build/export-anatomy
build/export-anatomy "$PWD/Design/Anatomy/generated"
```

SVG 注册画布为 320 × 440；透明 PNG 为 640 × 880。该命令使用当前路径源码并写入独立目录，不保证重现 v2 历史快照。v1、v2 资产保留用于回看。
