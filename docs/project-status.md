## 当前实现

| 能力 | 范围 |
| --- | --- |
| 公共食物 | 32 个内部条目，27 个可选择，5 个待补条目隐藏 |

| 消化示意 | 单份串行动画、器官聚焦、按需小结、独立重播 |
| 学习设置 | 关注主题和可选饮水背景；没有疾病问卷 |

待补公共条目为肉末茄子盖饭、牛肉粿条、鸡公煲、原味鸡（KFC）、新疆炒米粉。目录数量不代表数据已全部核实。

## 功能验收样例

历史验收记录包含：红烧肉 300 g、米饭 300 g、小笼包（猪肉）200 g，共 3 种、3 份、800 g。以下为功能测试样例，不是饮食建议或个人健康档案。

| 报告主题 | 记录结果 | 数据边界 |
| --- | --- | --- |
| 脂肪 | 118.9 g：红烧肉 90.0 g、小笼包 28.0 g、米饭 0.9 g | 当时采用英国 70 g 每日标签对照，结果为 169.9%；不是中国 NRV 或个人、单餐上限 |
| 嘌呤 | 467.7 mg：红烧肉 450.0 mg、米饭 17.7 mg | 小笼包未提供；为已记录小计，红烧肉仍采用旧估值 |
| 热量 | 1,900 kcal：红烧肉 1,050、小笼包 460、米饭 390 | 每日标签对照的 95.0%，不推断个人能量盈余 |

上述结果说明当前计算与呈现行为，不证明底层食物值全部可靠。红烧肉旧嘌呤估值、跨样本配方口径等仍需审阅，详见 [食物成分记录](food-composition-v8.md)。

## 数据与存储

| 数据或职责 | 实现 |
| --- | --- |
| 公共食物与来源 | `FoodDatabase`、`FoodDatabaseExpansion`、`FoodCompositionDatabase`，随应用打包 |
| 自建食物、最近使用 | App 沙盒 Application Support 下的 `FoodJourney/personal-foods.json` |
| 引导、关注、饮水偏好 | UserDefaults，键为 `FoodJourney.UserPreferences.v2` |
| 本餐份量 | `FoodItem` 值快照，由 `DigestionSession` 在内存中管理 |
| 汇总与分析 | `MealNutrientMatrix`、`MealFocusAnalysis` |
| 界面说明 | `FoodPresentation` 及各报告视图，与研究备注分离 |

公共数据不会被设备上的自建食物操作改写。保存成功后才更新食物库内存；文件读取失败时保留原文件并阻止覆盖。目前尚无导出、备份恢复或损坏记录修复入口。

当前没有账号、后端、云同步或云备份；本餐也不作为跨启动历史保存。可替换的存储接口只是架构准备，不代表账号隔离已实现。未来若接入账号，还需要鉴权、按账号隔离缓存、退出清理、游客迁移、冲突处理和恢复策略。

## 已知限制与待验证事项

2026-09-22 的静态审视发现：

- `AnatomyCalloutLayoutTests` 仍期待旧纤维及肝肾气泡文案，与当前实现不一致；断言尚未修正，当前版本回归未运行。
- 部分单元测试默认创建文件食物库，添加测试食品可能改写测试设备的最近使用；需先注入内存存储。
- 主画布存在固定小字号和固定高度；大字体、VoiceOver、减弱动态效果仍需完整体验验证。
- 工程声明 iPhone、iPad 与横屏支持，现有证据主要来自单一模拟器型号。
- 自建食物已校验数值范围，但明显矛盾的热量与成分组合仍可能通过。
- 公共数值证据链不均匀，部分字段沿用旧估值；复制为自建食物后的估算属性也需核对。
- 源码中保留旧三屏页面和代谢模型，当前主流程不使用其个人产物与容量预测。
- 当前源码树未见隐私清单，应用内尚缺完整隐私政策与支持入口。

这些结论来自 2026-09-22 的静态审视，未据此运行测试。应用发布仍需完成 [发布准备](release-readiness.md)。

2026-09-23 补充静态复核：

- `MealFocusAnalysis` 仍采用 70 g 脂肪、260 g 碳水、2,000 kcal 英国标签口径；“个人目标”出现在否定说明中，并非当前给用户设定了个人目标。大陆 NRV 适配及脂肪追加提示审阅尚未实施。
- `PersonalFood.validate()` 可接受合法名称及身份、其他宏量为零、每 100 g 脂肪 100 g 且热量为零的输入；属于静态确认的校验缺口，未实测保存。
- 预演和报告共享内存中的当前餐，未提供全天汇总或个人身体状态测量；“我”另有本机保存的偏好和食物库。
- 当前应用源码未发现独立隐私政策入口；已有本机存储说明及科普来源入口。

## 常用操作

- 搜索：消化预演 → 全部食物 → 搜索。
- 查看或删除本餐份量：消化预演 → 查看食物记录 → 删除对应记录。
- 管理自建食物：我 → 我的食物。
- 了解保存范围或清空最近使用：我 → 数据管理。

删除本餐某份记录与删除私人食谱是不同操作；重置本餐不会清空私人食物库。
