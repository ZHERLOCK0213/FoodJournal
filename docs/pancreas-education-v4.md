# v4 · 胰腺协作与整餐成分报告

2026-09-07 历史版本记录。v6 后讲解已改为静态三步，下文保留 v4 的设计与验证范围；当前状态见 [项目状态](project-status.md)。

## 问题背景

针对连续加入红烧肉和馒头后胰腺数值可能停止变化的问题，旧模型回归测试确认：

- 新会话各 100g 时，旧胰腺使用度从 2.4% 变为 40%，旧响应累计为 50（无临床单位）。
- 馒头 300g 即会触发旧胰腺“能力”上限；再加食物时旧百分比和响应可保持不变。
- 这些是旧代码的抽象计算结果，不是正常人体的真实容量或分泌规律。原问题记录缺少份量与会话前态，因此不能断言容量上限是唯一原因。

因此没有通过调大容量常数来让数字“看起来正常”，而是把用户可见报告与这一模型分离。历史引擎与其回归测试暂留，不在该阶段做全项目清理。

## 新的呈现

- `MealEducationSummary` 只汇总原始 `FoodItem` 的食物克数、碳水、蛋白、脂肪、纤维和热量，不依赖旧吸收率或器官能力。
- 报告汇总本餐全部食物，含每份成分明细；预演气泡仍对应最后一份。
- 胰腺讲解分「帮助消化」「血糖调节」两个入口，每个三步，可点选、播放与暂停。
- 画布预演使用短暂高亮；胰液的短虚线仅为流向示意，不是精确导管解剖，不把食团画进胰腺。
- 血糖讲解不预测浓度、升幅或胰岛素量；零碳水时说明是一般机制，不暗示胰岛素为零。
- 播放时长仅是阅读节奏。现实中的消化、吸收与激素调节会重叠发生。

## 内容来源与限制

- [NIDDK：消化系统如何工作](https://www.niddk.nih.gov/health-information/digestive-diseases/digestive-system-how-it-works)：胰液与消化酶进入小肠，协作分解食物；肝脏处理营养。
- [NIDDK：What Is Diabetes](https://www.niddk.nih.gov/health-information/diabetes/overview/what-is-diabetes)：胰腺制造胰岛素，帮助身体细胞利用葡萄糖。
- [NIDDK：胰岛素抵抗与糖尿病前期](https://www.niddk.nih.gov/health-information/diabetes/overview/what-is-diabetes/prediabetes-insulin-resistance)：细胞对胰岛素的反应涉及肌肉、脂肪、肝脏等，不能只看进食量当作个人反应。

2026-09-07 查阅。以上资料支持一般机制，不支持用食物克重推算个人激素量，也不替内置食物数据背书。当时的食物数据、引导和隐私准备后续另行演进，当前发布条件见 [发布准备门槛](release-readiness.md)。
