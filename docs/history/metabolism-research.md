# 代谢模型研究记录 · FoodJourney

记录起始日期：2026-08-11。本文保留早期代谢模型的审视过程及参考资料；不是当前功能说明，也不是经过验证的个人生理预测模型。当前产品状态见[项目状态](../project-status.md)。

当前教育链路记录食物成分和份量，展示一般消化路径及整餐成分汇总；不调用旧器官能力模型来预测个人吸收率、激素分泌、尿酸生成或排泄量。历史引擎仍留在源码中，不代表其中的系数已得到科学验证。

## 早期模型发现的问题

| 主题 | 早期实现或假设 | 审视结果与当前边界 |
| --- | --- | --- |
| 尿酸与蛋白质 | 按蛋白质克数乘固定系数估算尿酸，并在肾脏泡泡中显示“产生尿酸” | 混淆了蛋白质、嘌呤及产生/排泄过程。当前只汇总食物嘌呤参考值，不换算个人血尿酸或尿酸产量。 |
| 尿素 | 以尿酸代替蛋白质代谢相关的含氮废物说明 | 科普需要区分尿素与尿酸；增加术语本身不构成可用于个人的定量模型。 |
| 吸收后去向 | 只显示 ATP、二氧化碳、水等结果数值 | 当前以定性路径区分消化、吸收、运输和后续利用，不将食物成分克数直接等同个人吸收量。 |
| 肝脏与胰腺 | 肝脏主要显示 ATP，胰腺主要显示胰岛素 | 当前讲解区分肝胆协作、胰液帮助消化与胰岛素参与血糖调节；食团不进入这些辅助器官。 |
| 器官能力 | 固定初始能力，一餐内随进食递减，耗尽后按比例产生“未吸收”和“滞留” | 属于历史产品假设，没有建立可支持个人器官功能判断的证据。当前报告不使用这些输出。 |
| 纤维和乳糖 | 将其统一视作到达大肠的不可吸收残留 | 过度简化，不能据此判断某个人的吸收、耐受或残留量。当前保留成分信息及一般机制说明。 |

## 被弃用的定量推断示例

早期实现使用 `uricAcidPerProteinMg = 50 mg/g`。例如，输入含 31 g 蛋白质的食物会得到 `31 × 50 = 1,550 mg` 的模型结果。这里的算式仅用于解释旧代码的问题，**不是该食物实际生成尿酸的测量值或估计值**。

后来历史引擎引入 `purinePer100g`、尿素字段以及尿酸产生/排泄字段，这改善了数据概念的区分，但不能据此认为固定嘌呤转化系数、固定排泄比例或“器官能力点”足以预测个人结果。原记录中的食物嘌呤范围、每日生成量和固定器官储量缺少逐项可追溯证据，不作为当前产品规则保留。

## 保留的教育内容结构

以下为讲解主题，而非每份食物的产出计算公式：

| 部位 | 教育主题 |
| --- | --- |
| 口腔与胃 | 咀嚼、混合及食物的初步消化 |
| 小肠 | 进一步消化、营养吸收，以及血液和淋巴等运输路径 |
| 胰腺 | 胰液中的消化酶与胰岛素等激素的不同作用 |
| 肝脏与胆囊 | 营养处理、胆汁的制造、储存与释放 |
| 肾脏 | 血液过滤、调节及部分代谢废物排出；不是食团通道 |
| 大肠 | 水分回收、菌群参与及粪便形成 |

“食物输入成分”“消化与吸收机制”“体内实际结果”是不同层次。前两者可用于当前教育展示；第三者不能仅凭食物输入推导。尿酸相关的表述边界见[馒头数据与尿酸科普审计](../reference/food-data-and-urate-audit.md)。
