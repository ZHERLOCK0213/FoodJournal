## v7 设计范围

- 本阶段重点为学习主题与器官小结，食物数据扩充另行记录。
- 已知疾病/情况可帮助用户找到学习入口，保留，但不是完整疾病清单或诊断功能。

## 已修改与范围

1. 保留原4项健康情况，增加糖尿病、痛风、胃食管反流病、乳糖不耐受，以及“其他／列表中没有”。按与本App的消化/成分教学关联及官方资料选择，不声称依据用户量或患病率排名。
2. 首次引导与“我”共用`LearningPreferenceSections`，防止两处取消行为不同。新用户默认一般了解；旧v1偏好可解码，已有明确主题不擅自清空，可点击取消。
3. 内部`HealthFocus.general`代表没有特别关注，而非健康诊断。再次点击已选主题或点“无特别关注”均回到一般了解。
4. 条件只生成推荐按钮，按主题去重并列出推荐原因和来源。勾选/删除病种不自动改focus；关闭提供情况清空病种选择，保留用户明确选择的主题。仅选other或空选择不自动套用已知疾病专题。
5. 增加钠与血压、脂肪与血脂、反流与进食、乳糖消化主题；血糖、胰岛素、热量也有各自矩阵说明卡，尿酸保留既有卡。没有钠或脂肪类型等完整数据时只讲机制和数据边界，不计算个人风险、摄入目标或用药剂量。
6. `summaryPart`在打开弹层时保存目标器官，`MealJourneySummaryView`按该器官筛选结果；未聚焦入口传nil显示全部。本份食品名称和来源保留，器官小结不重复展示整份全部成分表。

## 推荐对应与该阶段核对的来源

这些链接支持科普主题的相关性，不代表疾病严重程度或个体饮食处方：

- 高血压 → 钠与血压：[NHLBI DASH](https://www.nhlbi.nih.gov/health/dash-eating-plan)。
- 高血糖、糖尿病 → 血糖/胰岛素：[NIDDK Healthy Living with Diabetes](https://www.niddk.nih.gov/health-information/diabetes/overview/healthy-living-with-diabetes)。
- 高血脂 → 脂肪与血脂：[NHLBI Blood Cholesterol](https://www.nhlbi.nih.gov/health/blood-cholesterol/treatment)。
- 高尿酸、痛风 → 尿酸：[MedlinePlus Gout](https://medlineplus.gov/gout.html)。
- 胃食管反流病 → 反流与进食：[NIDDK GERD](https://www.niddk.nih.gov/health-information/digestive-diseases/acid-reflux-ger-gerd-adults/eating-diet-nutrition)。
- 乳糖不耐受 → 乳糖消化：[NIDDK Lactose Intolerance](https://www.niddk.nih.gov/health-information/digestive-diseases/lactose-intolerance/eating-diet-nutrition)。

暂不广泛加入需分期、治疗背景或严格过敏/膳食安全数据才能支持的其他疾病；用户可选“其他”，不需要披露疾病名称。此项不解释为用户没有疾病。

## 历史版本验收方法

以下步骤仅适用于 v7。检查相应历史版本时，在 Xcode 选择测试设备并运行；问题记录应包含版本、设备、第一条错误及文件行号。当前版本不再提供下述疾病问卷。

1. 在“我”选择血糖，再次点击取消；报告回到一般讲解，不显示血糖专项卡。退出重开后选择仍正确。
2. 勾选糖尿病：出现血糖、胰岛素推荐，但当前关注点不自动变化。点击推荐后报告专题变化，矩阵克数不变化。再取消能回一般了解。
3. 同时勾高血糖和糖尿病：同一推荐主题只出现一次、原因包含两项。只勾“其他”或保持开启却不选：不自动出现已知疾病推荐。
4. 关闭“提供已知情况”：病种选择清空，已主动选的主题保留；重新打开不复活隐藏病种。勾反流、乳糖不耐受检查对应推荐及官方来源。
5. 预演水饺100g后选胃，打开胃小结：只有胃。关闭后选肝脏再打开：只有肝脏。点击查看全貌、再进本份完整旅程：展示全部器官。报告仍为整餐矩阵。
6. 若要检查首次引导，使用单独新模拟器/测试安装，避免为了验收清除现有个人偏好。应能直接跳过进入一般了解，也能不选任何情况/主题开始使用。

旧UI测试可能仍依赖旧问卷标签、默认热量或全器官小结行为，不能在未更新预期时用于宣称该阶段回归通过。v7 当日未运行、未扩写自动化测试。
