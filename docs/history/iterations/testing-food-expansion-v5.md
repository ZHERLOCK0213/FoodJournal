# 食物库 v5 手动验收

> 阶段档案：本页用于复现当时版本，不是当前完整验收清单；可复用案例需先对照现行行为。 当前契约见 [产品规格](../../PRD.md)，验证范围见 [项目状态](../../project-status.md)。

本清单对应 2026-09-09 的 v5 历史版本：新增20项目录，其中14项可预演、6项数据待补。v8 已补充蛋炒饭数据，v9 已隐藏待补条目，因此下列旧目录行为不作为当前版本要求。当前状态见 [项目状态](../../project-status.md)。

1. 打开食物目录，搜索「水饺」，检查菜肉水饺的做法、来源及记录编号。选200g预演：碳水28g、蛋白质11.6g、脂肪18.4g、热量320kcal、纤维2.8g。
2. 搜索「鸡公煲」，应找到「待补充」条目，不能开始数值预演；不能出现0kcal等冒充已知数据的显示。
3. 查看「汉堡」资料，确认明确标为相近参考，并说明国外白面包、牛肉饼和沙拉样本，不代表特定大陆品牌。
4. 小米粥纤维资料为未检出，不视作零。仅预演小米粥后，报告应提示纤维数据待补；加入水饺后应标示已知小计及缺失项，不能称完整整餐纤维总量。
5. 打开本餐记录，移除一份，报告和食物份数应同步变化；重置后清空。原有米饭、鸡胸肉仍可选择和预演。

v5 未处理非尿酸关注点的报告切换问题；后续疾病问卷移除见 [v9](personal-foods-v9.md)，整餐关注分析见 [v10](meal-focus-v10.md)。签名、归档、TestFlight与发行准备不在本清单范围内。
