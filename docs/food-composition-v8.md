# 食物成分补充 v8

核对日期：2026-09-10。代码已修改，未构建、运行测试或安装。以下覆盖数为源码盘点，不是运行验收结果。

## 本轮结果

- 目录保持32种；蛋炒饭解锁后27种可预演，5种仍待对应配方/成分。
- 可预演食物乳糖：26种有数值（包括限定无乳配方的0估算），1种蛋炒饭为Tr微量。没有把微量、空白、未检出统一填0。
- 可预演食物纤维：26种可汇总，1种小米粥仍为ND、无检测限。红烧肉主体近似0有估算说明。
- 可预演食物嘌呤：14种有参考/估算值，13种仍缺。其中11种接入本轮可追溯参考，另外馒头、红烧肉、苹果保留旧估值，继续标估算。
- 主要参考网站集中在“代谢报告→食物成分矩阵”底部；每行仅保留可折叠配方说明。食物目录使用同一辅助成分访问口径。
- 酸奶明确为“原味参考”，保留catalogID，宏量、纤维与乳糖改用同一原味全脂酸奶条目，不再混用未注明配方的均值。

## 来源与方法

1. [香港食安中心营养资料查询](https://www.cfs.gov.hk/tc_chi/nutrient/presearch3.php)：保留v5中式食品宏量和纤维记录，见food-expansion-v5-sources.md。
2. [英国CoFID 2021](https://www.gov.uk/government/publications/composition-of-foods-integrated-dataset-cofid)：读取官方xlsx的`1.3 Proximates`表。A列食品编号、B名称、C描述、J蛋白、K脂肪、L碳水、M kcal、W乳糖、Z AOAC纤维。每100g可食部分；字符串0.0是数值记录，Tr是微量，N/空白不等于0。
3. [FSANZ AFCD](https://www.foodstandards.gov.au/science-data/food-nutrient-databases)：F007828无添加三文鱼的乳糖和纤维均为0，仅用于这两项的普通鱼肉参考，不将熟鱼宏量移植到生鱼。
4. [USDA/ODS-NIH Purine Release 2 (2025)](https://www.ars.usda.gov/northeast-area/beltsville-md-bhnrc/beltsville-human-nutrition-research-center/methods-and-application-of-food-composition-laboratory/mafcl-site-pages/purine-content-of-foods/)：读取官方`PURINEDATABASEANDDATASOURCES2025.xlsx`。S列为四种嘌呤碱基总和mg/100g；T列是食物中的尿酸，不能拿来替代S列。

引用网站减少不等于丢弃逐项记录。`FoodCompositionReference.Value`保留source、record、isEstimate，`FoodCompositionDatabase`按稳定目录ID显式接入，不按任意同名自建Food自动推断。

蛋炒饭11-444，第2343行：蛋白4.3g、脂肪4.9g、碳水33.3g、186kcal、纤维1.1g、乳糖Tr；有数值乳糖的食物与其合并时显示“数值＋微量”。不能通过未给检测限的Tr推算出具体克数。

其余无乳配方估算明确限定原料，不声称所有同名食品都不含乳糖：馒头、油条、水饺、小笼包、虾肉烧卖、炒米粉、带卤豆腐脑、红烧肉等。参考原料记录见代码。含奶粉/奶油配方、品牌品或复杂浇头另核。红烧肉纤维以无蔬菜配菜、去整块香料的猪肉主体近似0；调料微量纤维未计，汇总显示“含估算”。

## 未采用的资料

- 哈尔滨医科大学结题报告（中国红十字基金会托管）表29列红烧肉109.2，但方法部分统一写干重、成品菜表未明确重申湿重且缺对应含水量；本轮不把109.2直接当熟食湿重mg/100g。链接：https://pic.crcf.org.cn/RedCrossFoundation/file/2024-03-29/17116975739972c91b79d8e5668be533018e8920386d2419.pdf
- 国内膳食指导附录的普通大米/小米是粮食原料，不能不经产率/水分换算填米饭/粥；mg/kg需除10才是mg/100g。橘子不替代橙子。
- 不以原料猪肉/鸡肉或其他名称的菜，冒充复合成品菜测量；不为了覆盖率新增大量无来源小数。
