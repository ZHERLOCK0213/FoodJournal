## 目标

画布需要清楚表达三件事：

1. 食物从可见的嘴部进入；
2. 食团沿连续的消化道路径前行；
3. 消化道与参与消化、代谢的辅助器官承担不同作用。

## 当前构图原则

- **入口**：口部朝右且可见，食物从画面右侧进入。
- **主体**：中央器官与局部口颈轮廓提供位置上下文，左右说明卡承载文字。
- **连接**：主食团路径保持连续，图层开口与动画中心线对齐。
- **层级**：消化道与肝、胆、胰等辅助器官明确区分；肾脏不构成食团通道。
- **聚焦**：选中器官居中放大，隐藏全消化道粒子以便阅读本地过程；背景旅程继续，退出恢复总览。早期保留聚焦粒子的方案已被取代。
- **说明**：气泡通过水平、竖直折线连接器官；选中气泡的详细说明在附近呈现。具体操作与命中边界以 [产品规格](../PRD.md) 为准。

## 解剖表达边界

FoodJourney 使用简化科普示意，不追求医学图谱的全部细节，但简化需要保留关键的相对位置和连接关系：

- 肝、胃的左右关系以人体自身为参照，不能因画面朝向而交换。
- 胃出口与十二指肠、小肠和大肠构成连续食团路径。
- 胆囊和胰腺以消化液协作关系解释，不表现为食物穿过的管道。
- 小肠的盘曲与大肠包围关系需要可辨识；形状是示意，不能用于判断真实长度或容积。
- 肾脏以血液过滤与排泄的延伸讲解呈现，不由动画位置推断个人代谢时间。

## 形状语言

- 外轮廓以连续 Bézier 曲线和圆角连接构成，保持小尺寸下的可辨识性。
- 小肠较细、较亮，回环之间保留负空间；大肠较粗，与小肠区分。
- 胃保留入口、大弯、小弯及出口方向，避免成为无辨识度的色块。
- 肝脏以宽阔形态体现体量，同时保留胃入口的可见性。
- 胰腺采用细长形态，与肠道区分。
- 同源矢量、器官锚点、命中区域和引线坐标共同维护，避免独立调整造成错位。

## 色彩与光效

以下为概念阶段建立的层级方向，具体颜色以当前素材和 App 实现为准：

| 层级 | 色彩方向 | 用途 |
| --- | --- | --- |
| 背景 | 深海军蓝 | 提供稳定对比度 |
| 人体上下文 | 深靛蓝及弱轮廓 | 提供位置线索 |
| 食物流 | 黄绿至暖金色 | 标识运动焦点 |
| 胃 | 暖珊瑚色 | 识别主要消化部位 |
| 肝 | 柔和酒红色 | 区分器官体量 |
| 胰腺 | 金赭色 | 与胃、肠区分 |
| 肠道 | 薄荷绿、蓝绿色 | 表现路径连续性 |

局部高亮用于说明正在讲解的部位，不让所有静态器官同时发光。颜色不能成为唯一的信息区分方式，文字标签和形状共同承担识别职责。

## App Icon

当前方向采用明确的胃形概念符号。[图标 v2](../../Design/AppIcon/v2/README.md)使用浅蓝背景与深蓝胃形，突出入口、胃底、弯曲和出口，不塞入完整器官图。早期“朝右张口的人”概念保留为演进资料。

图标不使用文字、餐具、医疗十字或心电线等泛化符号。小尺寸、不同背景和系统圆角裁切属于发布前的验证范围；历史概念预览不能代替正式资产验收。

## 资产与实现的验收关注点

- 各图层共用坐标，锚点、引线、命中区域与实际轮廓一致。
- 动画沿渲染中心线行进，不穿过无关器官或跳离路径。
- 说明卡、粒子和器官在目标屏幕及大字体条件下保持可读。
- 聚焦、重播、完成结果和手动小结之间的状态一致。
- 正式分发的原创资产与外部参考素材归属清楚。

概念母版的材质、局部光效和动效节奏属于设计探索，不能从概念图推断当前 App 已实现同样效果。视觉验证也不构成对健康知识或个人预测能力的验证。
