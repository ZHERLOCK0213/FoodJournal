# FoodJourney 发布准备

更新：2026-09-23。计划首发地区为中国大陆，平台为 iOS；没有固定发布日期。当前尚未进行 TestFlight 分发或 App Store 发布。此清单记录准备工作，不保证审核结果。

## 验证顺序

先完成内容与代码候选版本、数据隔离和针对性回归，再验证设备与发布材料，随后安排测试分发。正式提审前复核实际构建和当期规则，避免用旧截图或历史通过数量证明新版本质量。

拟新增器官展开与加速动画时，另验收阅读理解、静态替代和计算不受播放速度影响。多人餐需验证整道菜与个人份量的区别，避免把不完整输入呈现为完整个人摄入。

商品数据或未来云服务接入前，需按实际字段、接收方、保存方式和目的更新隐私说明。当前科普方向不把个人吸收量预测列为发布前置条件；若后续增加，应单独评估证据与适用要求。
