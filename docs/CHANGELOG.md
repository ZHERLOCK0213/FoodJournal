## 2026-09-25 · 未提交工作区记录：原画布器官聚焦、饭点提醒与大陆每日参考对照

本节功能代码与相关测试代码仅存在维护者本地工作区，尚未提交或推送；远端 `Dev` 不包含这些实现。本次文档提交保留其设计与验证记录，不代表功能交付。

- 器官探索改为原画布缩放并居中，以水平、竖直正交折线连接该器官的过程气泡；“查看说明／收起说明”控制就近说明卡，长文卡内滚动，同一时间一张。下方直接切换器官，支持空餐阅读、来源和缺项说明。
- 收起说明保留聚焦；点黑色空白退出聚焦并关闭说明，器官、气泡、说明卡和滚动不触发退出。移除上下重复的可视“查看全貌”按钮，保留 VoiceOver 返回全貌动作及退出手势。
- 内容随当前已加入旅程的快照刷新；改变下一份食品选择不会污染本份内容。聚焦隐藏全消化道粒子，旅程继续、不重复计入；“减少动态效果”取消缩放插值。
- 脂肪／碳水对照改为大陆 NRV 的 60 g／300 g；能量使用国标的 2,000 kcal 标签等价值。取消仅凭达到每日标签参考值就提示停止追加的规则。
- 收到上一轮界面的实际运行截图反馈，并据此调整上述交互；不据此认定全量验收通过。新增或更新相关内容、参考量、提醒及 UI 路径的测试代码；本轮修改仅作静态语法、差异与链接核查，未新增构建、应用测试运行或模拟器操作记录，待项目维护者在 Xcode 中验收。
- 整理五款山姆商品截图的标签基准和缺项，作为 SQL 入门前的数据练习，未接入应用或数据库；保留 FoodJourney 品牌。
- 保留“消化预演 / 代谢报告 / 我”三栏及名称。饭点提醒已接入源码：首次看过有数据的报告并离开报告页后提示一次，可允许默认每日 13:00、19:00，编辑两个每日时间或拒绝；“我”可更改和关闭。用户明确开启后才请求所需系统授权，拒绝不反复自动询问。
